# 要件定義

## 1. システム概要

ユーザが会議室の登録・予約を行うWebアプリケーション

## 2. ロール

| ロール | 説明                           |
| ------ | ------------------------------ |
| USER   | 会議室の予約・確認ができる。   |
| ADMIN  | ユーザ・会議室の管理ができる。 |

## 3. 機能一覧

| ID   | 機能                   | USER | ADMIN | GUEST | 備考                                      |
| ---- | ---------------------- | ---- | ----- | ----- | ----------------------------------------- |
| F-01 | ユーザ情報登録         | -    | -     | ○     | `ADMIN` は初期データとして登録する        |
| F-02 | ユーザ一覧取得         | -    | ○     | -     |                                           |
| F-03 | ユーザ詳細情報取得     | ○    | ○     | -     | `USER` は自分の情報のみ取得可能           |
| F-04 | ユーザ情報更新         | ○    | -     | -     | `USER` は自分の情報のみ更新可能           |
| F-05 | ユーザ情報削除         | -    | ○     | -     | `USER` は自分で情報削除できない           |
| F-06 | 会議室登録             | -    | ○     | -     |                                           |
| F-07 | 会議室一覧取得         | ○    | ○     | -     |                                           |
| F-08 | 会議室詳細情報取得     | ○    | ○     | -     |                                           |

| F-10 | 会議室情報削除         | -    | ○     | -     |                                           |

## 4. 業務ルール

- R-01: 会議室は9:00～21:00でのみ予約可能(9:00-9:30 ～ 20:30-21:00)
- R-02: 30分間隔で予約可能（例：9:00～9:30、9:30～10:00）
- R-03: 予約の開始日が、今日から7日以内
- R-04: キャンセルできるのは予約の開始時刻の24時間前まで
- R-05: 同じ会議室で時間帯が重なる予約はできない。ただし、一方の終了時刻と他方の開始時刻が同じ場合は、予約可能とする
- R-06: 現在時刻より前の予約はできない
- R-07: 終了時間は開始時間の後でなければならない
- R-08: キャンセル済みも含め、予約の記録が残っている限り削除不可
- R-09: 予約があるユーザは、削除不可
- R-10: キャンセル済みの予約は、R-05 の重なりの判定の対象外とする。

## 5. スコープ外（やらないこと）

- 予約の時間変更
- パスワードリセット
- メール通知
- 外部ツール連携
- 決済処理
- 各会議室使用率等のデータ集計
